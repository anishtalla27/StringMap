## Description

Learn where each note belongs on your guitar.

StringMap includes 18 original single-note exercises, from open strings and first-position melodies to dotted rhythms and string crossings. Read standard notation and tablature, hear the music, and follow the highlighted position on a six-string guitar fretboard.

Practice at your own pace. Pause and resume, restart, seek to a passage, and adjust BPM without changing pitch. Use measure loops, a metronome, and count-in. Your saved exercises remember their practice settings.

Explore alternate fingerings, left-handed fretboard display, tuning, capo, and transposition. All included music and playback work offline. No account, advertising, or subscription.

This first release focuses on single-note exercises. Photo scanning, chords, and file import are not included.

## Review instructions

No login, purchase, or server is required. Open Exercises, select Open String Walk, and tap Play. The highlighted notation and fretboard show the current note. Pause and resume with the same button; Restart clears any loop and returns to the beginning. Drag Playback position to seek. Practice includes BPM adjustment and loops. Exercises work in airplane mode. Settings contains privacy, support and license documents.
